# Ashlapov Calculator
## Практическая работа 2 · C# и WPF

**Автор:** Ашлапов Иван · **Группа:** ИПс-21

Калькулятор с отдельной библиотекой вычислений и тестами MSTest. Светлый интерфейс с зелёным дисплеем и историей последних 20 успешных расчётов.

### Возможности

- Сложение, вычитание, умножение, деление и степень: `+ - * / ^`.
- Приоритет операций и вложенные скобки: `2+3*4 = 14`, `(2+3)*4 = 20`.
- Степени справа налево: `2^3^2 = 512`.
- Отрицательные числа: `-2^2 = -4`, `(-2)^2 = 4`, `2^-2 = 0,25`.
- Дробные числа с запятой или точкой; округление до 10 знаков после запятой.
- Сообщения о делении на ноль, неверном выражении, скобках и недопустимом результате.
- После `=` цифра начинает новый ввод, оператор продолжает расчёт с результатом.
- История с восстановлением выражения по нажатию. Она хранится только до закрытия приложения.

### Управление

| Клавиша или кнопка | Действие |
|---|---|
| Цифры, `+ - * / ^ ( )` | Ввод выражения |
| `,` или `.` | Десятичный разделитель |
| `Enter` или `=` | Вычислить |
| `Backspace` или `⌫` | Удалить последний символ |
| `Esc` или `C` | Очистить ввод, сохранив историю |
| «Очистить» под историей | Удалить записи истории |

### Проекты решения

| Проект | Назначение |
|---|---|
| `AshlapovCalculator.Core` | Классы `Calculator` и `ExpressionCalculator`, .NET 8 |
| `AshlapovCalculator.Wpf` | Интерфейс WPF и модель представления, .NET 8 для Windows |
| `AshlapovCalculator.Tests` | 47 тестов MSTest: 8 для операций, 22 для выражений и 17 для модели представления |

Для проверки модели представления тестовый проект подключает `MainViewModel.cs` и `RelayCommand.cs` как связанные исходные файлы. Они не зависят от визуальных классов WPF.

### Запуск

Нужны Windows и .NET SDK 8 или новее. Для первого восстановления пакетов NuGet нужен доступ к сети.

1. Открыть `AshlapovCalculator.sln` в Visual Studio 2022 версии 17.8 или новее.
2. Назначить `AshlapovCalculator.Wpf` запускаемым проектом и нажать **F5**.
3. Для тестов открыть **Тест → Обозреватель тестов → Запустить все**.

Команды из папки решения:

```powershell
dotnet build AshlapovCalculator.sln -c Release
dotnet test AshlapovCalculator.sln -c Release
dotnet run --project AshlapovCalculator.Wpf -c Release
```

Проверено: **47 из 47 тестов пройдены**, сборка без ошибок и предупреждений.
